Mitra Personal Calendar

Personal, self-hosted calendar synchronization

About this application

This is a privately operated local installation of Mitra. It synchronizes Google Calendar events with the owner's local calendars through Google OAuth 2.0 and CalDAV.

Google permissions

With the owner's consent, the integration can discover calendars and read, create, update or delete calendar events. Authorization can be revoked from the owner's Google Account at any time.
